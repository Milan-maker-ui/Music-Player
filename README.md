# 🎵 Python Music Player

A simple desktop music player built with **Python**, **Tkinter**, and **Pygame**. The application allows users to select a folder containing MP3 files, display a playlist, and control music playback through an easy-to-use graphical interface.

---

## 📌 Features

- 🎼 Select a folder containing MP3 songs
- 📂 Automatically loads all MP3 files
- ▶️ Play music
- ⏸️ Pause and Resume playback
- ⏹️ Stop playback
- ⏭️ Play the next song
- 🔊 Volume control slider
- 📃 Playlist display
- 🖥️ Simple and user-friendly GUI

---

## 🛠️ Technologies Used

- Python 3.x
- Tkinter (GUI)
- Pygame (Audio Playback)
- pathlib
- os

---

## 📖 How to Use

1. Launch the application.
2. Click **Select Folder**.
3. Choose a folder containing **.mp3** files.
4. The songs will appear in the playlist.
5. Use the controls to:
   - Play
   - Pause
   - Stop
   - Next Song
6. Adjust the volume using the slider.
