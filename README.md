# 🎵 Python Music Player

A lightweight desktop music player built with Python, Tkinter, and Pygame.

## Features

- 📁 Load an entire folder of MP3 files at once
- ▶️ Play, Pause, Stop, and skip to the Next track
- 📋 Scrollable playlist with track names
- 🔊 Real-time volume control slider
- 🔄 Loops through your playlist automatically
